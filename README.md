# GENOS2_resources

A searchable, single-page reference for the **Yamaha Genos2** arranger workstation: voices, styles and drum kits.

**Live page:** https://woodypianoshack.github.io/GENOS2_resources/

## What's inside

| Tab | Contents |
|---|---|
| Voices | 2,066 voices, one table per category, with sub category and MSB / LSB / PC numbers |
| Styles | 800 styles, one table per category |
| Drum Kits | 75 drum and SFX kits with MSB / LSB / PC, and the full note map for each kit (note, sound, alternate group, note off, Revo!) |

Each tab has category jump links and a filter field. Press `/` to focus the filter and `Esc` to clear it. The Drum Kits tab can hide sounds that are identical to StandardKit, so only each kit's unique sounds are shown.

Tabs can be linked directly: `#voices`, `#styles`, `#kits`.

## Files

- `index.html`: the whole reference in one self-contained file. Open it locally in any browser, or view the live page above.

## Source

All data comes from the official **Yamaha Genos2 Data List** (`Genos2_DL_En_A0.xlsx`, published 11/2023), available from Yamaha's download site.
